# Beginner Stock Scorecard

A free, public, **educational** website that scores about 100 large US stocks and major ETFs from 0 to 100
and explains each score in plain English. It is not financial advice.

- A Python script (`scoring/`) runs every weekday evening on GitHub Actions, downloads prices from Alpaca
  (free IEX feed), scores every ticker and writes JSON files into `site/data/`.
- The website (`site/`) is plain HTML/CSS/JS that reads those JSON files. GitHub Pages hosts it for free.
- Each day's scores are committed back to the repo, which builds the honest **Track record** page over time.

## The score

| Part | Weight | What it measures |
|---|---|---|
| Trend | 30% | Price vs its 50- and 200-day averages, and 50-day vs 200-day |
| Momentum | 25% | 3, 6 and 12-month return compared with the S&P 500 (SPY) |
| Steadiness | 25% | Lower volatility and smaller recent drops score higher |
| Smart money | 20% (optional) | Net insider + congressional purchases minus sales, last 90 days |

If smart money is off (the default, since it needs a paid Quiver Quant key), the other three are reweighted to
37.5% / 31.25% / 31.25%. Labels: 70+ “Looks strong”, 40–69 “Mixed”, under 40 “Looks weak”.
All anchors and weights live in `scoring/score.py` and are published on the site's “How it works” page.

## Project layout

```
scoring/            Python: universe.csv (the stock list), score.py (the math), run.py (daily job)
site/               The website (open site/index.html through a local server, see below)
site/data/          Generated by the daily job: latest.json, stocks/*.json, history/*.json, track_record.json
tests/              pytest tests (fake price data, no internet needed)
.github/workflows/  daily.yml: score, save, publish
```

## Run it on your own computer (optional)

```bash
python -m venv .venv
.venv\Scripts\activate          # Windows  (macOS/Linux: source .venv/bin/activate)
pip install -r requirements.txt
pytest -q                       # run the tests
python -m scoring.run --demo    # FAKE prices, to preview the site (clearly marked as demo)
python -m http.server 8000 -d site   # then open http://localhost:8000
```

For real data locally, copy `.env.example` to `.env`, add your Alpaca keys, and run `python -m scoring.run`.
Don't commit demo data: delete `site/data` (or run the real job) before pushing.

## Keys and secrets

Keys are **never** stored in the code. On GitHub, go to **Settings → Secrets and variables → Actions** and add:

| Secret | Required | Where to get it |
|---|---|---|
| `ALPACA_API_KEY` | yes | Alpaca dashboard → API Keys |
| `ALPACA_SECRET_KEY` | yes | shown once when you generate the key |
| `QUIVER_API_KEY` | no | Quiver Quant API (paid) |

To switch smart money off even with a key, add a repository **variable** (same page, “Variables” tab)
`ENABLE_SMART_MONEY` = `false`.

## Publishing (GitHub Pages)

1. Push this folder to a GitHub repository (branch `main`).
2. **Settings → Pages → Build and deployment → Source: GitHub Actions**.
3. **Actions → “Score stocks and publish site” → Run workflow** for the first run.
   After that it runs automatically every weekday evening.

## Changing the stock list

Edit `scoring/universe.csv` (ticker, name, sector, type). Keep to large, established companies and major ETFs.
